OpenEngine 0.1 is a 2D game engine and visual Studio with Lua scripting, Box2D-based
physics, sprites, UI, audio, and the Dead Signal zombie survival example.

## Downloads

- **OpenEngineStudio-Windows.zip**: ready-to-run Windows x64 Studio. Extract the ZIP
  into a folder and run **OpenEngineStudio.exe**. Keep all extracted files together.
  No Node.js or Lua installation is required.
- **DeadSignal-source.zip**: the game's Lua scripts, scene, sprites, license, and an
  embedded **DeadSignal.openengine** document. Extract it, then open that document
  from Studio using **Open**. Press **Play** to run the game.
- **SHA256SUMS.txt**: checksums of the two downloadable ZIPs.
- GitHub's **Source code** links contain the complete engine and example source at
  this release's version tag.

Move with WASD or arrow keys, aim with the mouse, and hold left click or Space to
fire. Clear waves, buy upgrades, and survive until your health reaches zero.

The Windows distribution is unsigned. Shared runtime and native export functionality
were tested on Linux; the Windows executable itself was cross-packaged and has not
been launch-tested on Windows.

See README.md and docs/ in the source code for the tutorial, API, architecture,
packaging instructions, and validation details.
